# Java/Spring Boot backend vibe-coding
This repository contains the complete dataset created for the research presented in the scientific paper "**Comparative Evaluation of LLM-Generated Code Quality and Architectural Robustness in Backend Software Engineering**" published in the journal *Electronics* on 25 June 2026.

**The developed dataset is available only for research and non-commercial use.**

The paper can be accessed here: <a href="https://doi.org/10.3390/electronics15132805" target="_new" rel="noopener">https://doi.org/10.3390/electronics15132805</a>.

If you are using the dataset please correctly cite the paper as:

M. Horvat, I. Ursić, and K. Krmpotić, "Comparative Evaluation of Gemini and DeepSeek for LLM-Generated Code Quality and Architectural Robustness in Backend Software Engineering," *Electronics*, vol. 15, no. 13, Art. no. 2805, 2026, doi: 10.3390/electronics15132805.
